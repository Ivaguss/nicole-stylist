# Материалы для соцсетей

Прайс в разных форматах — для Telegram, сторис и переписки с клиентами.
Файлы в этой папке **не публикуются на сайте**: GitHub Pages отдаёт только `public/`.

| Файл | Что это |
|------|---------|
| `prices.txt` | Прайс текстом. Сверху короткая версия для вставки в сообщение, ниже подробная — что входит в каждую услугу |
| `nicole-prices-story.png` | Картинка-прайс 1080×1920 для сторис |
| `story-source.html` | Исходник картинки. Шрифты вшиты в файл, поэтому открывается и без интернета |

## Как перерисовать картинку

Поправить текст или цены — прямо в `story-source.html`, затем пересобрать PNG:

```bash
npx playwright screenshot \
  --viewport-size=1080,1920 \
  marketing/story-source.html \
  marketing/nicole-prices-story.png
```

Вёрстка рассчитана ровно на 1080×1920: содержимое начинается с 176 px сверху
и заканчивается на 1710 px, чтобы имя и кнопка с Telegram не ушли под интерфейс
сторис. Если добавляете строки — следите, чтобы страница не выросла выше 1920 px,
иначе низ обрежется.

## При изменении цен

Цены продублированы в нескольких местах — меняя, пройдите по всем:

- `public/services/index.html` — страница «Услуги и цены»
- `public/index.html` — карточки услуг на главной, строка «А также», блок «Полный комплекс»
- `marketing/prices.txt`
- `marketing/story-source.html` → перерисовать PNG

Зачёркнутая цена пакета должна сходиться с суммой трёх услуг, которые в него входят.
